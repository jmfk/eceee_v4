# Ändra i topp navigationen

Ändra i topp navigationen

1. Öppna sidredigerare för sidan som innehåller navigationen som används på webbplatsen. Detta
2. Expandera Navigation-platsen för att visa navigeringswidgetens rad.
3. Hitta navigeringswidgeten som styr den offentliga menyn.
4. Klicka på inställningsikonen på navigeringswidgetens rad.
5. Ändra den synliga menyetiketten från Papers till For authors.
6. Kontrollera att länken fortfarande pekar på den avsedda informationssidan för författare.

# Edit themes

Manage colors, typography, component styles, and image styles.

<!-- narration: Themes control the visual system, including colors, fonts, component styles, image styles, and reusable presentation settings. -->

1. Open Settings, then Themes.
2. Choose the theme you want to edit.
3. Update the relevant theme tab and save changes.
4. Preview affected pages before relying on the changes in production.

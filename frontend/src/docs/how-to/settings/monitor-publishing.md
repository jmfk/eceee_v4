# Monitor publishing

Use publishing views to review scheduled, live, and bulk publication work.

<!-- narration: Publishing tools help you review live, scheduled, and bulk publication work before content changes go public. -->

1. Open Settings, then Publishing.
2. Use the dashboard for current publication status.
3. Use the timeline for scheduled changes.
4. Use bulk operations when many pages need the same publication action.

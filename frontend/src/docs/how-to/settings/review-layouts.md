# Review layouts

Inspect page layout templates and their available slots.

<!-- narration: Layouts define the page structure and available slots, so review them before choosing how a page should be built. -->

1. Open Settings, then Themes.
2. Edit the theme whose layouts you want to review.
3. Open the Layouts tab and review its layout and slot structure.
4. Use layout information when choosing the right structure for a page.

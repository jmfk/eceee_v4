# Sidebar top news widget

Show compact featured news in a sidebar.

<!-- narration: Use the Sidebar Top News widget for small featured-news lists in sidebar layouts. -->

1. Add or edit a Sidebar Top News widget in a sidebar slot.
2. Choose the source or featured-news criteria.
3. Set the item count to fit the sidebar height.
4. Keep titles short enough for the compact layout.
5. Preview beside the main content.

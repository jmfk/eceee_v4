# Table widget

Configure responsive data tables.

<!-- narration: Use the Table widget when tabular data needs structure and responsive behavior. -->
<!-- goal: In this walkthrough, we add the Table widget to a page slot and open its settings. -->
<!-- why: This matters because each widget type has its own purpose, and choosing the right widget keeps the page easier to maintain. -->
<!-- outcome: After this walkthrough, you should know where to add the Table widget and where to continue configuring it. -->

1. Add or edit a Table widget.
2. Enter column headings before adding body rows.
3. Configure alignment, spans, and styling only where they clarify the data.
4. Keep tables narrow enough to work on mobile, or use responsive settings.
5. Preview with realistic row and column counts.

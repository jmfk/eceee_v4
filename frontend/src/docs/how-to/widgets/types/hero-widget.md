# Hero widget

Configure a prominent hero section with text and media.

<!-- narration: Use the Hero widget for the main visual introduction of a page or landing section. -->

1. Add or edit a Hero widget in the intended hero slot.
2. Enter the main heading and supporting text.
3. Select the image or media that should carry the hero visually.
4. Configure colors, alignment, and optional before or after text.
5. Preview the hero at mobile and desktop sizes.

# Image widget

Display a single image, gallery, carousel, or video-style media item.

<!-- narration: Use the Image widget when media is the primary content in a slot. -->
<!-- goal: In this walkthrough, we add the Image widget to a page slot and open its settings. -->
<!-- why: This matters because each widget type has its own purpose, and choosing the right widget keeps the page easier to maintain. -->
<!-- outcome: After this walkthrough, you should know where to add the Image widget and where to continue configuring it. -->

1. Add or edit an Image widget.
2. Select the image or media collection.
3. Choose the display mode, such as single image, gallery, or carousel.
4. Configure captions, lightbox, random order, and auto-advance only when needed.
5. Preview the result to confirm image sizing and cropping.

# Skärmbildsregister

Varje scen ska få en skärmbild från den inloggade produktionssajten i Chrome. Berättarrösten nedan hör till respektive bild och kan visas som undertext.

### 01. 1. Hitta objekttypen

**Bildfil:** `01-1-hitta-objekttypen.jpg` (fångad från Chrome)

**Visa:** Öppna Publisher från huvudnavigeringen. Visa listan över huvudobjekttyper och därefter Supporting objects.

**Säg / visa som undertext:** «Publisher är platsen där vi hanterar återanvändbart, strukturerat innehåll, till exempel artiklar, personer och evenemang. Börja med att välja vilken objekttyp du vill arbeta med. Under Supporting objects hittar du kompletterande typer grupperade efter sin huvudtyp.»

### 02. 2. Hitta eller skapa ett objekt

**Bildfil:** `02-2-hitta-eller-skapa-ett-objekt.jpg` (fångad från Chrome)

**Visa:** Öppna en objekttyp, sök efter ett befintligt objekt och visa dess rad. Gå tillbaka och visa knappen för att skapa nytt.

**Säg / visa som undertext:** «Sök först efter objektet så att du inte skapar en dubblett. Öppna ett befintligt objekt för att ändra det, eller välj New när du behöver lägga till ett nytt. Vilka fält du ser beror på objekttypens datamodell.»

### 03. 3. Navigera objektets innehåll

**Bildfil:** `03-3-navigera-objektets-innehall.jpg` (fångad från Chrome)

**Visa:** Öppna objektet. Visa huvudobjektet, vänsterkolumnens träd för underobjekt och relaterade objekt samt formuläret. Ändra storlek på en kolumn och fäll ihop/ut den.

**Säg / visa som undertext:** «I redigeringsvyn kan du navigera mellan rotobjektet, underobjekt och relaterade objekt. Dra avdelaren för att ge formuläret mer plats, eller fäll ihop en kolumn. Kolumnens formulärinnehåll finns kvar när du fäller ihop den.»

### 04. 4. Spara innan du byter

**Bildfil:** `04-4-spara-innan-du-byter.jpg` (fångad från Chrome)

**Visa:** Gör en ofarlig ändring. Visa sparknapp och byte till ett annat objekt utan att faktiskt förlora ändringen. Visa eventuellt varning/dialog om den finns i miljön.

**Säg / visa som undertext:** «Spara dina ändringar innan du byter objekt eller lämnar en widgetredigerare. När du navigerar i objektträdet sparar Publisher en arbetskopia innan nästa objekt öppnas. Om sparningen misslyckas stannar du kvar i det aktuella objektet.»

### 05. 5. Kontrollera version och publiceringsstatus

**Bildfil:** `05-5-kontrollera-version-och-publiceringsstatus.jpg` (fångad från Chrome)

**Visa:** Visa status- och versionsinformationen för objektet, utan att trycka på publicera.

**Säg / visa som undertext:** «Innan innehåll blir live ska du kontrollera versionen och publiceringsstatusen. Att spara en arbetskopia och att publicera är olika steg. Följ behörigheterna och publiceringsflödet som gäller för just den här objekttypen.»


> Skärmbilderna är faktiska Chrome-fångster från `app.eceee.org`, sparade utan att ändra eller publicera innehåll. Vyer som krävde ett nytt förslag eller en fungerande Designer-arbetsyta kunde inte visas i prod.

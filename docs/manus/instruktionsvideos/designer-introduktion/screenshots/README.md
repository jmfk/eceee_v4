# Skärmbildsregister

Varje scen ska få en skärmbild från den inloggade produktionssajten i Chrome. Berättarrösten nedan hör till respektive bild och kan visas som undertext.

### 01. 1. Öppna temat

**Bildfil:** `01-1-oppna-temat.jpg` (fångad från Chrome)

**Visa:** Öppna Designer och välj tema från temalistan.

**Säg / visa som undertext:** «Designer är en avgränsad arbetsyta för att justera ett temas visuella egenskaper. Öppna det tema du har fått åtkomst till. Vilka delar du kan redigera styrs av tilldelad behörighet.»

### 02. 2. Orientera dig

**Bildfil:** `02-2-orientera-dig.jpg` (diagnostisk fångst från Chrome; visar endast “Loading Designer workspace…” och är inte en färdig instruktionsbild)

**Visa:** Visa temats navigation och förhandsvisning. Peka ut områden för färg/palett, typografi, marginaler och padding samt temaassets, utan att gå in på alla detaljer.

**Säg / visa som undertext:** «Arbetsytan samlar inställningar för bland annat färger, typsnitt, marginaler, padding och assets. Förhandsvisningen hjälper dig att bedöma hur ändringen påverkar temat. Börja med en egenskap i taget och kontrollera resultatet.»

### 03. 3. Förstå utkastet

**Bildfil:** `03-3-forsta-utkastet.jpg` (kunde inte fångas: Designer-arbetsytan fastnar på “Loading Designer workspace…” i prod)

**Visa:** Ändra en ofarlig egenskap och visa uppdaterad förhandsvisning. Visa Save draft och Publish changes, men publicera inte.

**Säg / visa som undertext:** «Ändringar visas i arbetsytans utkast. Save draft sparar utkastet, men ändrar inte den live-publicerade designen. Publish changes är det separata steget som gör de verifierade ändringarna live.»

### 04. 4. Håll koll på delat arbete

**Bildfil:** `04-4-hall-koll-pa-delat-arbete.jpg` (fångad från Chrome)

**Visa:** Versionshistoriken för Industry-temat. Restore-kontrollerna syns men används inte.

**Säg / visa som undertext:** «Utkastet delas av dem som har Designer-åtkomst till samma tema. Om någon annan har ändrat temat kan en äldre vy behöva uppdateras innan du fortsätter. Läs statusmeddelanden och spara ditt arbete innan du lämnar arbetsytan.»


> Skärmbilderna är faktiska Chrome-fångster från `app.eceee.org`, sparade utan att ändra eller publicera innehåll. Vyer som krävde ett nytt förslag eller en fungerande Designer-arbetsyta kunde inte visas i prod.

> Arbetsytan fastnade på “Loading Designer workspace…” för flera teman, inklusive eceee Editorial och System Default. Bilden `02-2-orientera-dig.jpg` dokumenterar laddningsläget; övriga detaljer som kräver den fungerande arbetsytan är inte fångade.

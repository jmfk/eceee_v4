# Skärmbildsregister

Fånga scenerna i staging med en demobild utan personuppgifter. Förändringar av fokusmetadata och banners får inte göras i produktion. Bildtexterna nedan är även berättarröst/undertext. `blocked` betyder att scenens beteende inte ska beskrivas som fungerande innan det har verifierats.

### 01. Öppna fokuspunktens verktyg

**Status:** missing

**Bildfil:** `01-oppna-fokuspunktens-verktyg.jpg`

**Visa:** Mediabiblioteket med vald demobild i redigering och knappen Choose focus point.

**Säg / visa som undertext:** «En fokuspunkt anger vilken del av bilden som ska hållas kvar när en layout beskär bilden. Öppna bildens inställningar i mediabiblioteket och välj Choose focus point.»

### 02. Placera fokus på motivet

**Status:** missing

**Bildfil:** `02-placera-fokus-pa-motivet.jpg`

**Visa:** Dialogen med markören placerad på motivet, Horizontal/Vertical-reglagen och procentvärdena.

**Säg / visa som undertext:** «Placera markören på den del som ska prioriteras, till exempel personens ansikte. Du kan klicka eller dra på bilden och finjustera med reglagen Horizontal och Vertical. Värdena anger positionen från bildens vänstra respektive övre kant.»

### 03. Jämför olika beskärningar

**Status:** missing

**Bildfil:** `03-jamfor-olika-beskarningar.jpg`

**Visa:** Landscape, Portrait och Square samtidigt. Använd ett motiv utanför mitten så att skillnaden syns.

**Säg / visa som undertext:** «Samma bild kan beskäras på olika sätt i olika format. Förhandsvisningarna Landscape, Portrait och Square visar hur utsnittet förändras. Fokusmarkeringen hjälper beskärningen att behålla motivet när bildrutan har ett annat format.»

### 04. Spara och kontrollera värdet

**Status:** missing

**Bildfil:** `04-spara-och-kontrollera-vardet.jpg`

**Visa:** Spara fokuspositionen i staging, öppna dialogen på nytt och visa den kvarvarande markören. Visa Reset to center utan att ändra den sparade demobilden.

**Säg / visa som undertext:** «Välj Save focus för att spara positionen på bildfilens metadata. Öppna dialogen igen för att kontrollera att punkten finns kvar. Reset to center återställer förhandsvisningen till mitten; spara bara om det är den position du vill använda.»

### 05. Visa fokus i banner med bild

**Status:** blocked — kontrollera bannerkopplingen först

**Bildfil:** `05-banner-text-mode-square-rectangle.jpg`

**Visa:** I staging, jämför samma bild i Banner Text Mode med Square och Rectangle. Visa centrumläge och sparad fokusposition i den faktiska sidförhandsvisningen. Stoppa om utsnittet inte reagerar på fokusmetadata.

**Säg / visa som undertext:** «I en banner kan samma bild visas i ett kvadratiskt eller rektangulärt utsnitt. Jämför de två layouterna med samma fokuspunkt och kontrollera i sidförhandsvisningen att motivet ligger kvar där det ska.»

### 06. Visa fokus i Header Mode

**Status:** blocked — kontrollera bannerkopplingen först

**Bildfil:** `06-banner-header-mode-desktop-mobil.jpg`

**Visa:** I staging, jämför Header Mode med bakgrundsbild vid desktop- och mobilbredd, i centrumläge och med sparad fokusposition. Fortsätt endast om renderaren använder fokusmetadata.

**Säg / visa som undertext:** «Header Mode använder bilden som bannerbakgrund. Kontrollera utsnittet både på stor och liten skärm. När layouten beskär bilden hjälper fokuspositionen till att behålla den viktiga delen i bild.»

### 07. Sammanfatta

**Status:** missing

**Bildfil:** `07-sammanfatta-fokuspunkt.jpg`

# Skärmbildsregister

Varje scen ska få en skärmbild från den inloggade produktionssajten i Chrome. Berättarrösten nedan hör till respektive bild och kan visas som undertext.

### 01. 1. Ändra och granska

**Bildfil:** `01-1-andra-och-granska.jpg` (kunde inte fångas: Designer-arbetsytan fastnar på “Loading Designer workspace…” i prod)

**Visa:** Gör en liten, lätt igenkännbar ändring och visa hur förhandsvisningen uppdateras.

**Säg / visa som undertext:** «När du ändrar en inställning arbetar du först i Designer-utkastet. Förhandsvisningen hjälper dig att bedöma resultatet, men den betyder inte att ändringen redan är live.»

### 02. 2. Spara utkastet

**Bildfil:** `02-2-spara-utkastet.jpg` (kunde inte fångas: Designer-arbetsytan fastnar på “Loading Designer workspace…” i prod)

**Visa:** Välj Save draft och visa bekräftelse/status.

**Säg / visa som undertext:** «Save draft sparar de godkända värdena i det delade utkastet. Live-temat påverkas inte. Andra designers med åtkomst kan arbeta vidare i samma utkast.»

### 03. 3. Publicera ändringarna

**Bildfil:** `03-3-publicera-andringarna.jpg` (kunde inte fångas: Designer-arbetsytan fastnar på “Loading Designer workspace…” i prod)

**Visa:** Kontrollera den samlade ändringen. Välj Publish changes i testmiljön och visa resultatet.

**Säg / visa som undertext:** «När ändringarna är granskade väljer du Publish changes. Systemet kontrollerar att utkastet fortfarande bygger på aktuell version och publicerar de förberedda ändringarna tillsammans.»

### 04. 4. Ångra senaste publicering

**Bildfil:** `04-4-angra-senaste-publicering.jpg` (kunde inte fångas: Designer-arbetsytan fastnar på “Loading Designer workspace…” i prod)

**Visa:** Visa Undo publish i testmiljön. Aktivera och visa att tidigare version återställs.

**Säg / visa som undertext:** «Om den senaste publiceringen behöver återtas kan Undo publish återställa den senaste revisionen, förutsatt att det delade utkastet inte har nya ändringar som gör återställningen osäker. Kontrollera alltid status och koordinera med andra som arbetar i temat.»


> Skärmbilderna är faktiska Chrome-fångster från `app.eceee.org`, sparade utan att ändra eller publicera innehåll. Vyer som krävde ett nytt förslag eller en fungerande Designer-arbetsyta kunde inte visas i prod.

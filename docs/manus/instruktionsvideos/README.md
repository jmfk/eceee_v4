# Manus för instruktionsvideor

Manusen är inspelningsunderlag för korta svenska instruktionsvideor i ECEEE CMS. Varje fil beskriver målgrupp, ungefärlig längd, förberedelser, bildhandling och berättarröst. UI-texter kan skilja sig något mellan versioner; följ den aktuella miljön vid inspelning.

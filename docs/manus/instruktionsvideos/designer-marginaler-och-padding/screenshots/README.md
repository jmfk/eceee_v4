# Skärmbildsregister

Varje scen ska få en skärmbild från den inloggade produktionssajten i Chrome. Berättarrösten nedan hör till respektive bild och kan visas som undertext.

### 01. 1. Skilj marginal från padding

**Bildfil:** `01-1-skilj-marginal-fran-padding.jpg` (kunde inte fångas: Designer-arbetsytan fastnar på “Loading Designer workspace…” i prod)

**Visa:** Visa en komponent med tydlig yttre och inre luft. Lägg gärna en enkel grafisk markering ovanpå videon: marginal utanför komponenten, padding mellan kanten och innehållet.

**Säg / visa som undertext:** «När ett element ligger för nära något annat handlar det ofta om marginal. När text eller bild ligger för nära elementets egen kant handlar det ofta om padding. Börja med att avgöra vilken av de två situationerna du ser.»

### 02. 2. Hitta rätt inställning

**Bildfil:** `02-2-hitta-ratt-installning.jpg` (kunde inte fångas: Designer-arbetsytan fastnar på “Loading Designer workspace…” i prod)

**Visa:** Öppna Designer-sektionen för marginaler och padding. Visa grupperna eller kontrollernas namn och koppla en kontroll till komponenten i förhandsvisningen.

**Säg / visa som undertext:** «Leta upp inställningen som hör till rätt del av temat. Ändra inte flera relaterade värden samtidigt; då blir det svårt att förstå vilken ändring som gav resultatet. Notera först nuvarande värde och enhet.»

### 03. 3. Ändra stegvis och jämför

**Bildfil:** `03-3-andra-stegvis-och-jamfor.jpg` (kunde inte fångas: Designer-arbetsytan fastnar på “Loading Designer workspace…” i prod)

**Visa:** Ändra ett värde i liten omfattning. Vänta på att förhandsvisningen uppdateras. Visa före/efter och prova vid behov ett andra breakpoint eller en annan vy.

**Säg / visa som undertext:** «Gör en liten justering och kontrollera förhandsvisningen. Se om avståndet blev bättre utan att texten blir trång eller att layouten tappar balans. Kontrollera gärna en smal vy också, eftersom samma ändring kan upplevas olika vid olika bredder.»

### 04. 4. Spara som utkast

**Bildfil:** `04-4-spara-som-utkast.jpg` (kunde inte fångas: Designer-arbetsytan fastnar på “Loading Designer workspace…” i prod)

**Visa:** Visa den slutliga förhandsvisningen och välj Save draft. Visa bekräftelsen/statusen. Låt Publish changes vara orörd.

**Säg / visa som undertext:** «När resultatet ser bra ut sparar du utkastet. Det gör inte ändringen live. Publicering görs separat när ändringarna är granskade och redo.»


> Skärmbilderna är faktiska Chrome-fångster från `app.eceee.org`, sparade utan att ändra eller publicera innehåll. Vyer som krävde ett nytt förslag eller en fungerande Designer-arbetsyta kunde inte visas i prod.
